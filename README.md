# lema-rag-json
JSONification of the LEMA dataset

(https://www.mq.edu.au/macquarie-archive/lema/)

# warning
While all care has been taken in transfering the dataset from html to json, there may be some data losses.

# formating description
```      {
        "id": "LEMA-JOUR-1791-124", - Archive name / entry type / year / entry number
        "type": "journal", - Entry type
        "date_written": "1791-12-18", - Date written
        "date_range": null, - Date range if known
        "writer": "Lachlan Macquarie", - The writer of the entry
        "recipient": null, - Recipient of the note/letter
        "source_reference": "https://www.mq.edu.au/macquarie-archive/lema/1791/", - The known source
        "content": "Decr. 18. \n We moved to a new Ground of Encampment about a Quarter of a Mile to the Right.", - The content in full, as written
        "notes": null, - Curators notes if needed
        "summary": null, - Data summary if needed
        "location_written": null, - Location written if known
        "tags": null - Tags if needed 
      }
```
